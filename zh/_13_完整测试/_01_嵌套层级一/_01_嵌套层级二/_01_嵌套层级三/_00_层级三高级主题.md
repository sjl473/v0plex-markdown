## 微分方程

$$
\frac{\partial u}{\partial t} = \alpha \nabla^2 u
$$

## TypeScript 实现

```typescript
interface HeatEquation {
    alpha: number;
    initialCondition: number[][];
    
    solve(timestep: number): number[][];
}

    constructor(
        public alpha: number,
        public initialCondition: number[][]
    ) {}
    
    solve(timestep: number): number[][] {
        // Implementation
        return this.initialCondition;
    }
}
```
